# Dokumentasi Skorcast

Selamat datang di pusat dokumentasi Skorcast. Folder ini berisi catatan tiap
pengerjaan di project Skorcast: **apa** yang ditambahkan, dan **kenapa**
dipilih teknologi/pendekatannya — supaya bisa dipelajari ulang di lain waktu.

Situs ini dibangun dengan [MkDocs](https://www.mkdocs.org/) (theme Material)
dan di-deploy statis ke `docs.skorcast.online`.

## Daftar dokumentasi

- **Agentic AI**
  - [LangGraph](langgraph.md) — kenapa pakai LangGraph untuk agentic AI, flow
    penerapannya di Skorcast, dan dampaknya.
  - [Setup Agentic AI (POC)](agentic-setup.md) — scaffold agent Python + HTML
    testing + bridge Laravel.

## Konvensi

Tiap tambahan fitur/pendekatan di Skorcast didokumentasikan di sini: jelaskan
**apa yang ditambah** dan **kenapa** dipilih — bukan sekadar cara menjalankannya.
